### 19:20 打包与真机验证

`build.py` 用 PyInstaller `--onefile --windowed`。

第一版 52.9 MB。启动后内存 8.5 MB —— 以为没起来，查了进程树才发现
PyInstaller 会先起引导进程再解包跑真应用（真应用 111 MB）。

**留了个坑**：日志目录用 `sys.executable`（exe 旁边），素材用 `sys._MEIPASS`
（临时解包目录）。这是有意的——素材只读，日志要让玩家找得到。
但第一次写的时候两个都用了 `__file__`，结果日志写进了临时目录，玩家找不到。

### 18:00 美术：从「程序化生成」改成本地出图

我最初的计划是**全程序化绘制**（三角形屋顶 + 噪声山脊）。理由是「exe 不带外部资源」。

用户一句「**宝宝，我们是有做图软件的**」把我拉回来了。

已跑在 8188 端口，RealVisXL_V4.0 / animagine-xl-3.1 / Flux / Z-Image）。

**决策**：美术走本地 SDXL 出图，音效仍然 numpy 合成（因为音效出图软件帮不上忙）。

**理由**：程序化几何图形撑不起「水墨雪夜」这个题材。而 SDXL 出的第一张
测试图就直接定下了整个美术方向。

**代价**：exe 从「几十 KB」变成 53 MB。可接受——玩家不在乎 53 MB。

### 17:20 美术方向的两次修正

第一次测试出三张图，风格完全不同：
1. 雪夜山口（油画 + 水墨）
2. 驿站小屋（水彩）
3. 驿卒立绘（写实厚涂）

三张都好，但不能混用。**决策**：定义两个「族」——
- **场景族**：水彩 + 水墨，冷靛蓝 + 暖琥珀，统一前缀
- **人物族**：厚涂写实，暖褐灰，暗背景

所有 prompt 前缀固定，只变内容。这样 20 张图能保持一个整体感。

**踩的坑**：`ending_bad` 的提示词写「荒废、窗黑、门半开、没有一盏灯」，
SDXL 还是给了张暖色黄昏的漂亮小屋——因为风格前缀里的「warm amber palette」
把它拉跑了。重写提示词，把 `sunset, golden hour, warm light, lit windows`
加进负面词，才出对。

**教训**：负面词不够狠的时候，风格前缀的力量比内容描述大。

### 16:00 平衡：先算，后写

在写 `sim.py` 之前先算了一遍行进公式。

```
nights = ceil(距离 / (骑手脚力 × 马脚力 × 天气系数 × 灯系数 × BASE_TRAVEL))
```

试了 1.8 / 2.0 / 2.2 / 2.4 四个 BASE 值，把 3 骑手 × 3 马 × 3 路线的组合全打出来看。

**选 2.0 的理由**：慢组合（1.15×1.10）走北口要 2 夜，快组合（1.25×1.20）只要 1 夜。
这个差别正好让「谁配谁」有实际意义，同时雪天能把这个差别抹平（谁来都是 2 夜）。

**这一步省了很多返工。** 如果先写代码再调，会改得很痛苦。

### 15:00 概念定稿

从三个候选里选了「驿站驿丞」：

| 候选 | 落选原因 |
|---|---|
| 殖民地生存 | 和 Frostpunk 太像，25 分钟做不出新意 |
| 密函破译 | 纯信息游戏，缺少资源层的对抗 |
| **驿站驿丞** | 「信息不确定 + 资源稀缺 + 时间压力」三层都有，而且题材冷门 |

**核心机制选择**：天气预报七成准。

当时想的很明确——**如果预报百分百准，最优解唯一；如果完全不预告，就变成撞运气。
七成刚刚好：够你算，但不保证。**

这个设计在实现时被 S-01 毁掉了（界面直接告诉了玩家真实答案），
但设计意图本身是对的。

## 关于测试的三条教训

### 1. 单测测「函数返回什么」，测不了「玩家看到什么」

`travel_nights()` 的单测全过。但它默认用真实天气这件事，
只有**看到界面上那个数字、再对比实际发生的事**才能发现。

**可以补的**：给 `PlayScene` 加一个「渲染快照」测试——用固定状态渲染，
比对关键文本。这次没做，是缺口。

### 2. 模拟器自己可能也在作弊

`sim_balance.py` 一直报「合适」。因为它和界面犯的是同一个错——用真实天气决策。

**教训**：**评测工具本身必须被评测。** 至少在改完任何「信息可见性」相关的东西之后，
用两条独立的路径（AI 策略 + 手动打局）交叉验证一次。

### 3. 必须打满一局

这个项目里**每一个严重问题**（S-01 泄漏、S-02 躺平通关、S-03 卡死、S-04 方差过大、
S-05 S 不可达）都是「完整打完 12 夜」才会暴露的。

前几次都在第 5–7 夜被 bug 挡住就转去修别的了——
**修 bug 变成了逃避「打通」的借口。**
