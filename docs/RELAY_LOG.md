修完（见 `CHANGELOG.md` 0.5.1 ③、`ISSUES.md` S-18）：

```
smart（会算账 + 只接余量>=1）   达标 71.2%   S 27.2%   ← 文档那套数，现在可复现
base （会算余量、不会算账）      达标 47.6%   S 15.6%
```

**S 阈值扫描（同一批 500 局）**：82→16.2% / 80→20.6% / 79→23.0% /
78→24.8% / **77→27.2%** / 76→29.0% / 75→32.2%。77 的落点没问题。

**给 GPT 复核时的口径修正**：71.2% 是强 AI 的成绩，不是新手成绩。
