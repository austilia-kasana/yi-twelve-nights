# 变更记录

## 0.2.0 — 2026-11-23

「打满一局之后才发现的问题」专项修复。0.1.0 的问题是：**从没有人真正完整玩过 12 夜**，
所以所有「只在完整对局里才浮现」的缺陷都留到了玩家手上。

### 核心平衡（全部由实测驱动）

- **`FAITH_PER_DELIVER` 2.0 → 2.8**。原值下只读预报认真打，达标率仅 41%、S 率 12%——
  每个决定都做对也只有四成能守住，S 基本靠运气。新值：达标 73%、S 38%。
- **遇劫罚则减半**。原来八百里遇劫一次 -20 信（总信量的 1/4），而触发概率只有 5%。
  一次骰子就能抹掉四夜的进度——那不是难度，是方差。现在扣一半（-7~10）。
- **马每夜自然恢复 +2**。原来马不喂就永远停在低值，玩家会在第 6 夜左右突然发现
  「全员瘫痪」且不知道该怎么补救。实测这个改动几乎不影响难度曲线（S 率 37%→39%），
  纯粹是给失误留一条自救路径。
- **评价档位补齐 D（20–40）、E（0–20）**。原来 15 信和 40 信都是 C。

### 界面

- **修掉信息泄漏**：「预计 N 夜」原来用**真实天气**算，等于在派出去之前就告诉玩家
  一定能赶上——GDD 里写的「赌预报」根本不存在。现在用预报算，并对天气敏感的路
  额外标「变天则误」。
- **信条加三条刻度**：守（60）/ A（70）/ S（80）。原来看不出 S 线在哪。
- **日志从 4 行扩到 7 行**，标题「昨夜」→「近况」。打到第 9 夜时已经记不清第 5 夜了。
- **加「清空本夜」按钮**。误点后只能逐个取消，很容易点错。
- **加休息提示**：「歇着：某某（体力 +35/夜）」＋「马不跑也会自己回 +2/夜」。
  原来看不出「什么都不派 = 休息」。
- **整备面板加 × 关闭按钮**（点面板外也行）。原来只认 Esc，纯鼠标玩家会卡死在面板里。

### 工具

- **修掉评测工具的信息泄漏**：`tools/sim_balance.py` 的 AI 也调用了不传天气的
  `travel_nights()`，即用真实天气决策——相当于作弊，测出的难度比玩家实际面对的
  偏低约 8 个百分点（通关 81% vs 73%）。现在统一用 `gs.forecast`。
- 新增 `tools/ai_optimal.py`：策略搜索器，可扫多组参数找最优打法。
- 新增 `tools/play_seed17.py`：按预计算序列自动操作，用于回归验证。

### 验证

- 25 个单元测试全过
- 400 局模拟：通关 73%，S 38%，信中位 74
- **手动打满一局拿到 S**：种子 17，信 83，送达率 89%（16/18），逐夜决策见
  `logs/run-*-win.txt`

## 0.1.0 — 2026-11-23

首个可玩版本。

### 核心

- 十二夜回合制循环：黄昏收信 → 排班 → 夜间模拟 → 黎明结算 → 整备
- 三名资源：信（失败线）、金、油
- 三条路线，各自的天气抗性不同（北口怕雪、河渡怕雨、矿道免疫天气）
- 五种天气，随夜幕推进恶化
- **天气预报只有 70% 准确** —— 整个游戏的信息核心
- 骑手体力 / 马匹状态的双重消耗，逼出轮换与预算选择
- 五类夜间事件（顺风 / 迷路 / 落石 / 遇劫 / 无事），概率受天气调制
- 三种信件（寻常 / 加急 / 八百里），期限由路线基准夜数推导
- 商店：雇骑手、买马、喂料、添油、修路（每条路只能修一次）
- 胜负判定 + S/A/B/C 评价

### 画面

- 1280×720，pygame-ce
- 20 张美术素材，本机 ComfyUI + RealVisXL 生成
  - 标题 / 主背景 / 两种结局
  - 三条路线立绘
  - 五种天气图标
  - 四张骑手立绘、两张马立绘
  - 纸纹 / 漆木纹
- 程序化飘雪（三层视差）、灯火余烬、震屏
- 水彩 + 水墨的美术方向，冷靛蓝 + 暖琥珀

### 声音

- 七个音效，全部 numpy 合成，无外部音频文件
  - click / chime / fail / bell / horse
  - wind / drone（循环环境音）
- mixer 不可用时自动静音，不影响游戏

### 工程

- 核心逻辑与渲染完全分离，`relay/core/` 不 import pygame
- 25 个单元测试，全部通过
- 批量平衡模拟工具（`tools/sim_balance.py`），500 局验证通关率
- 素材生成工具链（`tools/comfy_client.py` + `gen_assets.py`）
- 素材缺失时自动生成替身图，游戏不会崩
- PyInstaller 单文件打包（`build.py`）

### 已知问题

- 中文字体依赖系统，缺失时中文显示为方块
- 无存档
- 单一难度
- `horse_dark` / `horse_grey` 的提示词带「frontier horse」，出图偏写实，和骑手立绘的风格略有差异

### 验收后修的 bug（同日）

真机 GUI 完整跑过一遍后发现并修复：

1. **躺平可过关** —— 十二夜全不派信，仍判「撑过了十二夜」。
   破坏性最强的一个：最优解变成「什么都不做」。
   修法：`total == 0` 时一律判负，结局文案「十二夜过去了，你一封也没派出去。」
2. **整备面板排版** —— 按钮名居中、价格右对齐，两者撞在一起；面板底部大片空白。
   修法：名字左对齐、价格右对齐，面板高度跟内容走。
3. **标题页残留文案** —— 底部写着「每夜只能问十二次以内的事」（从别的项目抄过来的）。
4. **「怎么玩」按钮不可见** —— ghost 样式在亮雪地上几乎透明，改成 normal。
5. **送达率 0/0 显示 0%** —— 一封信没派时应该显示「—」。
